# 하루결

메모, 할 일, 캘린더를 한 화면에서 관리하는 웹 메모장입니다. 세 기능이 서로 연결되어 동작합니다.

## 주요 기능

- **메모**: 작성·수정·삭제, 검색, 태그(업무/공부/아이디어/기타), 상단 고정
- **할 일**: 마감일·D-day, 우선순위, 필터, 진행률
- **캘린더**: 월간 달력, 일정 색상 지정, 매주·매월 반복 일정
- **수정**: 할 일과 일정을 삭제 없이 바로 수정
- **백업**: 화면 아래 "내보내기"로 데이터를 파일로 저장하고, "가져오기"로 다시 불러오기
- **시작 모드**: 처음에는 예시 데이터가 들어 있고, "빈 화면으로 시작"으로 비울 수 있음
- **연결**: 할 일 마감일이 캘린더에 자동 표시되고, 날짜를 누르면 그날의 일정·마감 할 일·메모가 함께 보입니다. 홈에서는 오늘 상태를 한눈에 볼 수 있습니다.

## 실행 방법

`index.html` 파일 하나로 만들어져 있어 설치가 필요 없습니다.

1. `index.html`을 더블클릭해 브라우저로 엽니다.
2. (선택) macOS에서는 `시작.command`를 더블클릭하면 로컬 서버가 켜지고 `http://localhost:5001`이 열립니다.

## 데이터 저장

데이터는 사용하는 브라우저의 localStorage에 저장됩니다. 서버나 회원가입이 필요 없지만, 다른 기기나 다른 브라우저와는 공유되지 않습니다. 화면 아래 "예시 데이터로 초기화" 버튼으로 처음 상태로 되돌릴 수 있습니다.

## 사용 기술

HTML, CSS, JavaScript (프레임워크 없음)
